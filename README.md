# 计算语言学入门词典

这是计算语言学入门词典的第一版静态网站，当前包含：

- 50 个候选词条目录
- 50 个词条的入门级释义、例句和应用
- 分类筛选
- 中英文搜索
- 词条详情、例句、应用和资料来源区域
- 响应式布局

直接在浏览器打开 `index.html` 即可预览。后续可以继续把词条数据拆分到 JSON 或 Markdown 文件，并增加音频、视频和图片资源。

## 发布成公开链接

这是纯静态网站，不需要数据库或后端。将整个文件夹上传到任意静态托管平台即可获得公开网址。

最简单的发布方式：

1. 将本文件夹上传到 GitHub 仓库。
2. 在仓库的 Settings > Pages 中选择 `main` 分支和根目录。
3. 保存后，GitHub Pages 会生成一个 `https://...` 公开链接。

也可以把整个文件夹拖到 Netlify、Vercel 等静态托管平台。发布时请保留 `index.html`、`styles.css` 和 `app.js` 在同一目录。
